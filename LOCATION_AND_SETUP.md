# GHOST — Your Codex project folder

This ZIP is intentionally **flat**. Extract its contents directly to your selected directory: `Documents\ghost` (usually `C:\Users\<username>\Documents\ghost` on Windows).

Expected examples:

- `Documents\ghost\AGENTS.md`
- `Documents\ghost\CODEX_PROJECT_MASTER_PROMPT.md`
- `Documents\ghost\CODEX_START_PROMPT.md`
- `Documents\ghost\docs\MASTER_SPEC.md`
- `Documents\ghost\docs\research.md`

Open **`Documents\ghost`** as the Codex workspace, read `START_HERE.md`, then use `CODEX_START_PROMPT.md` to begin Gate A1. This kit is the project specification and handoff, not a compiled Windows app.
