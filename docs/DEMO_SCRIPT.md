# A five-minute Invey demonstration

**Introduce:** “Invey keeps useful screen references accessible without constantly switching windows. Pocket keeps them; Workspace compares them; Ghost explores a separate logical interaction channel.”

**Pocket:** Start the explicit demo profile. Show a labeled sample, then capture a non-private real region. Preview the actual crop, Save, Open reference, Pin and Tuck shelf. Point out that samples are synthetic while this new reference is a real approved capture.

**Workspace:** Load two references into A and B. Select one, move, resize and fit its image. Start the explicitly labeled simulated Ghost demo to move B. Ordinary mouse ownership remains independent; this does not show live hand control.

**Ghost:** Open Ghost Tracking. Enable the recorded model sequence if remote camera access is unavailable. Stop, select SIMULATED calibration practice, Enable and Calibrate. Show the actual status and local practice target. If physically appropriate, deliberately choose and enable a real camera instead. Never call a recorded sequence live.

**Persistence:** Stop tracking, Exit and relaunch the same profile. Reopen the saved library and supported pinned cards.

**Finish:** “The future goal is hand interaction with Pocket through an independent logical channel, without taking over the mouse. Live tracking, wrist-out fingertip continuity and gesture actuation remain experimental.” Stop and Exit.
