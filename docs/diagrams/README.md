# GHOST — Diagram sources

These thirteen focused diagrams describe the intended local Windows system. Camera and UIA are isolated local children, not cloud services. Permission flow uses ordinary OS user context and explicit camera/capture/automation intent, with no sign-in service. Startup begins camera off. Runtime claims require actual acceptance evidence.
