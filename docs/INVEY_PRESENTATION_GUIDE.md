# Invey presentation

From the repository folder run `scripts\Start-Invey-Presentation.cmd`. This opens the existing separate demo profile with synthetic sample references. Camera stays OFF; the exhausted camera guardian is retained.

“Invey keeps useful screen references close at hand. Pocket saves and floats them; Workspace supports independent Mouse and Ghost ownership. Ghost is a separate logical pointer. Physical webcam control is experimental and currently fails motion-quality acceptance.”

1. Open Pocket and a sample reference. Open **Try Ghost Beta**, Start preview. Under Advanced, Refresh targets and Aim at the card if keyboard aiming is difficult.
2. Enable focused keyboard steering: arrows/WASD move Ghost, Shift gives small steps. Explicitly Arm Pocket, hold Space to grab, move, release Space to drop. Pin the card with Pin. These are labeled controlled inputs, not webcam detections.
3. Show the ordinary mouse still moves independently. Keyboard steering uses focus in its panel; use the existing Workspace simulated Ghost demonstration to show separate Mouse/Ghost owners on two references.
4. Stop/Escape hides Ghost and releases its claim. Exit from the main window closes the app. Tracking can show Recorded input separately; it cannot grant live actions.

If the route fails, Stop and use Pocket with the normal mouse: capture/preview/save/open/pin, then compare two references in Workspace. Do not enable a camera or change normal profile data.
