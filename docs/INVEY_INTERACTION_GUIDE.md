# Controlled Workspace bridge

Open Workspace and load different saved references into A and B. **Simulated Ghost demo** explicitly starts and arms the controlled source. It moves B using the coordinator while the mouse may independently hold A. Press the same demo control again to stop; closing Workspace also releases Ghost. Existing mouse/keyboard controls remain available.

This checkpoint routes controlled input to actual Workspace content. It does not connect camera gestures, shelf reveal, floating-card movement or pinning to Ghost. Those Execution20 features remain pending. Camera tracking stays subject to the exhausted diagnostic allowance; no new live test is authorized.

The coordinator releases its Ghost claim on invalid evidence, stale/order failures, removal, Stop or Pause. A new controlled source token is required after Stop. The Windows mouse is never moved by this adapter.
